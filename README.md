# Trakswell Home — eski adres yönlendirmeleri

Demo 7 Kasım 2026 tarihinde kaldırıldı. Bu depoda yalnız eski bağlantıları https://trakswellhome.com/ üzerindeki karşılıklarına taşıyan yönlendirmeler bulunur.

Ana site ve yönetim paneli Hostinger üzerinde yayınlanır. Bu depoya site çıktısı veya özel kaynak kodu eklemeyin.

GitHub Pages HTTP yönlendirme kuralları sunmadığından her eski sayfa sıfır saniyelik HTML meta refresh ve yeni canonical adresini kullanır. JavaScript yalnız sayfa içi bağlantıyı (ör. #teklif) korur; kapalıysa HTML yönlendirmesi çalışır.
